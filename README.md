# My CV Repository (RenderCV)

Este repositorio contiene el código fuente de mi currículum en formato YAML, renderizado utilizando [RenderCV](https://rendercv.com/). 

## 📂 Estructura del Proyecto

- `cv-en.yaml`: Versión en inglés del currículum.
- `cv-es.yaml`: Versión en español del currículum.
- `README.md`: Este archivo con instrucciones.


## 🚀 ¿Cómo generar el PDF?

### Opción A: Web (Rápido)
1. Ve a [rendercv.com](https://rendercv.com/).
2. Copia el contenido de tu archivo `cv-en.yaml` o `cv-es.yaml` y pégalo en el editor web.
3. Haz clic en "Render" y descarga tu PDF.

### Opción B: CLI (Local - Recomendado)
Si tienes Python instalado, puedes instalar RenderCV localmente:

pip install rendercv
